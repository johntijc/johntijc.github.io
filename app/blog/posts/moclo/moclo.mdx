# An introducion to MoClo
In the synbio pipeline, there are many "layers" which must work together to produce the
end solution. The upper layers... However, at the very lowest layer, the building blocks for all of
these more complex systems need to be readily available. This is where MoClo comes in: a collection
of useful building blocks to enable the abstract designs of the higher layers to be realized physically.

In MoClo, we gather genes coding for a variety of useful proteins and keep them on a set of readily
accessible plasmids in a way that's easy to combine with other genes to build these larger synbio
symbols. The result is a MoClo toolkit, which then enables the rest of the synbio pipeline to produce
useful solutions. In my particular case, I am working on a MoClo toolkit for antibodies.

# Antibodies
There are currently very few MoClo toolkits for antibodies. It would be very useful to compile
genes encoding various types of antibodies. Further, due to the modular structure of antibodies,
we can obtain the genes coding for each domain of the antibodies instead of needing to obtain genes for
all possible combinations. Since antibodies are very good at specific interaction, the applications of this would be extremely broadly, ranging over everything
from immunology research and flourescence, to sensors and purification. Essentially, any situation where
we need to control which particles interact with each other can benefit from better MoClo toolkits for
antibodies.

# Parts
There is near infinite variation in what antibodies may look like, and every time
someone gets infected, their adaptive immune system develops new antibodies to fight
that particular infection. Antibodies have both constant and variable domains. For a MoClo
kit, it is most important to first establish the constant domains that need to be used.
